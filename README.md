# 한국 간판 100년

첨부 사진 112장을 파일명의 연대순으로 배치한 스크롤 웹사이트입니다. 사진 파일의 바이트와 가로세로 비율을 유지했습니다. 건물·거리 사진 74장만 중앙 공간 투영에 사용하며, 단독 간판·인쇄물은 목록과 확대 보기에서만 표시합니다. 원래 있던 `11:3index.html`은 보존했습니다.

## VS Code에서 실행

1. 전체 폴더를 열고 VS Code Live Server로 `index.html`을 실행하거나, 터미널에서 다음 명령을 실행합니다.

   ```sh
   cd /workspace/overloads
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

2. 로컬 브라우저에서 서버의 `index.html`을 엽니다. 파일을 더블클릭하는 `file://` 실행은 ES 모듈·텍스처 보안 제한으로 지원하지 않습니다.
3. HTML·CSS·JS 분리본은 `index.html`, `styles.css`, `app.js`입니다. `archive.json`, `projections.json`, `vendor/`, `assets/`를 함께 유지합니다. npm 설치나 API 키는 필요하지 않습니다.
4. `single.html`은 CSS·JS·Three.js·JSON을 HTML에 합친 버전입니다. 원본 사진은 공통 `assets/photos/`에서 읽으므로 이 폴더를 함께 유지하고 동일한 HTTP 서버로 실행합니다. JSON 수정 후에는 `python3 scripts/build-single.py`로 다시 생성합니다.

## 사진과 설명

- 연대는 ZIP 이름이 아니라 사진 파일명의 앞 네 자리로 구분합니다. 파일명이 개별 촬영 연도를 증명하지 않으므로 UI에는 `1960s`와 같이 표시합니다.
- 설명과 제도 문구는 첨부 「한국 간판 100년 — 간판의 역사와 변천사 보고서」 6–12쪽의 시대별 내용을 요약했습니다. 보고서에 개별 사진 식별 정보가 없어 장소·작가·정확한 촬영일은 추정하여 붙이지 않았습니다. `archive.json`의 `sourcePage`가 PDF 페이지 근거입니다. 사진 설명은 해당 시대의 일반적 특징이며 개별 사진 재료 감정이 아닙니다.
- 왼쪽 사진과 중앙 사진을 누르면 원본 비율로 확대합니다. 휠·핀치로 최대 8배 확대하고 드래그로 이동할 수 있습니다. 왼쪽 목록의 모든 사진을 확대할 수 있으며, 뒤돌아가기 버튼 또는 Escape로 복귀합니다.
- 전체 UI는 지정된 네 색만 사용합니다. 원본 사진과 사진에서 샘플링한 하늘 색은 원본의 색을 유지합니다. 별도 폰트 파일이 지정되지 않아 시스템 본문 산세리프 글꼴을 사용했습니다.

## Tour into the Picture 설정

`projections.json`에 사진별 설정을 분리했습니다. 세 예시는 `projection-examples.json`입니다.

| 예시 | 사진 | 초기 소실점 | 하늘 |
| --- | --- | --- | --- |
| 중앙 거리 | 1960-31.webp | 0.49, 0.49 | far-plane |
| 치우친 골목 | 1980-03.jpeg | 0.77, 0.50 | gradient |
| 넓은 하늘 | 1960-11.webp | 0.51, 0.56 | far-plane |

이 값들은 사진을 보고 지정한 초기 추정값입니다. 다른 공간 사진은 공통 초기값에서 시작하므로 전시 전 사진별 보정이 필요합니다. 사진만으로 실제 건물 깊이나 가려진 내용을 복원할 수는 없습니다.

주소에 `?debug=1`을 붙이면 5개 영역, 소실점, 뒷벽 핸들이 표시됩니다. 가운데 점은 소실점, 나머지 두 점은 뒷벽의 좌상단·우하단입니다. 드래그 중에 공간을 재구성하며, 하늘 모드 선택과 JSON 저장을 지원합니다. 저장한 JSON으로 `projections.json`을 교체합니다. `leftWall.enabled` / `rightWall.enabled`를 false로 두면 그 면은 #101010이 됩니다. VP는 뒷벽 내부에 두어야 합니다.

중앙은 BoxGeometry 대신 별도의 PlaneGeometry 5개를 사용합니다. 한 번 읽은 사진 텍스처를 공유하고, 각 면의 3×3 homography를 프래그먼트 셰이더에서 동차 나눗셈으로 평가합니다. 단순 사각형 UV 보간이 아닙니다. 뒷벽에서 VP를 지나는 광선을 앞쪽 경계까지 연장해 면을 만들며, 정규화 좌표를 원본 가로세로 비율로 보정합니다. 깊이는 VP 기준 뒷벽의 수축률과 사진 FOV에서 계산하며 `depth`는 그 결과의 배율입니다. 사진만으로 절대 거리나 초점거리를 알 수 없어 FOV는 50° 모델을 사용합니다.

소스 사진 밖으로 나간 좌표는 샘플링 전에 버려 픽셀 늘림을 막습니다. 면 경계는 3px 중첩과 알파 페더를 적용하고, 원본 사진 외곽은 4px로 어둡게 감쇠합니다. 하늘은 photo / 샘플링 gradient / 별도 먼 평면 중 선택합니다. 먼 평면은 사진 공간의 상단 다각형만 마스킹하므로 벽이나 바닥을 덮지 않습니다. 카메라는 촬영 위치에서 작은 폭으로만 이동하고 회전 입력은 좌우 ±16°, 상하 ±6°로 제한합니다. 움직임 줄이기 설정에서는 정지합니다.
