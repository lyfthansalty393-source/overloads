# 한국 간판 100년

첨부 사진 112장을 파일명의 연대순으로 배치한 스크롤 웹사이트입니다. 사진 파일의 바이트와 가로세로 비율을 유지했습니다. 건물·거리 사진 74장은 중앙의 5면 정육면체 공간으로 투영하며, 단독 간판·인쇄물도 중앙에 원본 비율의 큰 사진으로 표시합니다. 원래 있던 `11:3index.html`은 보존했습니다.

## VS Code에서 실행

1. 전체 폴더를 열고 VS Code Live Server로 `index.html`을 실행하거나, 터미널에서 다음 명령을 실행합니다.

   ```sh
   cd /workspace/overloads
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

2. 로컬 브라우저에서 서버의 `index.html`을 엽니다. 파일을 더블클릭하는 `file://` 실행은 ES 모듈·텍스처 보안 제한으로 지원하지 않습니다.
3. HTML·CSS·JS 분리본은 `index.html`, `styles.css`, `app.js`입니다. `archive.json`, `projections.json`, `vendor/`, `assets/`를 함께 유지합니다. npm 설치나 API 키는 필요하지 않습니다.
4. `single.html`은 CSS·JS·Three.js·JSON을 HTML에 합친 버전입니다. 원본 사진은 공통 `assets/photos/`에서 읽으므로 이 폴더를 함께 유지하고 동일한 HTTP 서버로 실행합니다. JSON 수정 후에는 `python3 scripts/build-single.py`로 다시 생성합니다.

## 사진과 설명

- 연대는 ZIP 이름이 아니라 사진 파일명의 앞 네 자리로 구분합니다. 파일명이 개별 촬영 연도를 증명하지 않으므로 UI에는 `1960s`와 같이 표시합니다.
- 오른쪽의 재질·기술·표현 변화와 제도 문구는 첨부 「한국 간판 100년 — 간판의 역사와 변천사 보고서」 6–12쪽의 시대별 내용을 요약했습니다. `archive.json`의 `eras[].sourcePage`가 근거 페이지이며, 재질·기술·표현 문구는 `materialChange`에 분리해 #560e45로 표시합니다.
- 모델 아래 설명은 112장 각각의 사진에서 실제 보이는 글씨·사람·건물·간판 배치를 직접 관찰해 작성했습니다. 반복되는 시대 설명은 제거했습니다. 촬영 장소·작가·정확한 촬영일·확인할 수 없는 재료는 추정하여 붙이지 않았습니다. 개별 `descriptionBasis`에 근거를 표시했습니다.
- 사용자가 요청한 Fontclub(http://www.fontclub.co.kr/?p=1569), 경향신문(https://www.khan.co.kr/article/201512041942565) 원문 접근은 현재 환경의 네트워크 정책에서 403으로 차단되었습니다. 두 사이트 허용 도메인을 환경 설정 초안에 저장했지만 실행 환경에 적용된 것으로 간주하지 않습니다. 따라서 현재 사진 설명은 해당 기사 캡션과 대조·검증된 문구가 아닙니다. `captionResearch`와 `articleVerification`에 대조 대기 상태를 기록했습니다. 설정 적용 후 원문과 사진을 대조해 설명을 보완해야 합니다.
- 왼쪽 사진을 누르면 그 사진으로 이동합니다. 공간 모델은 더블클릭 또는 Enter로, 단독 간판은 클릭으로 원본 사진을 확대합니다. 휠·핀치로 배율 제한 없이 확대·축소하고 드래그로 이동할 수 있습니다. 왼쪽 목록의 모든 사진을 확대할 수 있으며, 뒤돌아가기 버튼 또는 Escape로 복귀합니다.
- 전체 UI는 지정된 네 색만 사용합니다. 원본 사진과 사진에서 샘플링한 하늘 색은 원본의 색을 유지합니다. 본문은 이전 버전의 시스템 산세리프를 유지합니다. 되돌아가기 버튼은 공식 Pretendard v1.3.9 가변 글꼴을 로컬 포함해 14pt(18.6667px), 자간 -0.3px, #fafafa로 표시합니다. 배경·테두리·외곽선 없이 `< 되돌아가기`만 표시합니다. 글꼴 라이선스는 `assets/fonts/PRETENDARD-LICENSE.txt`입니다.

## Tour into the Picture 설정

`projections.json`에 사진별 설정을 분리했습니다. 세 예시는 `projection-examples.json`입니다.

| 예시 | 사진 | 초기 소실점 | 하늘 |
| --- | --- | --- | --- |
| 중앙 거리 | 1960-31.webp | 0.49, 0.49 | photo |
| 치우친 골목 | 1980-03.jpeg | 0.77, 0.50 | gradient |
| 넓은 하늘 | 1960-11.webp | 0.51, 0.56 | photo |

이 값들은 사진을 보고 지정한 초기 추정값입니다. 다른 공간 사진은 공통 초기값에서 시작하므로 전시 전 사진별 보정이 필요합니다. 사진만으로 실제 건물 깊이나 가려진 내용을 복원할 수는 없습니다.

주소에 `?debug=1`을 붙이면 5개 영역, 소실점, 뒷벽 핸들이 표시됩니다. 가운데 점은 소실점, 나머지 두 점은 뒷벽의 좌상단·우하단입니다. 드래그 중에 공간을 재구성하며, 하늘 모드 선택과 JSON 저장을 지원합니다. 저장한 JSON으로 `projections.json`을 교체합니다. `leftWall.enabled` / `rightWall.enabled`를 false로 두면 그 면은 #101010이 됩니다. VP는 뒷벽 내부에 두어야 합니다.

중앙은 BoxGeometry 대신 별도의 PlaneGeometry 5개를 사용합니다. 한 번 읽은 사진 텍스처를 공유하고, 각 면의 3×3 homography를 프래그먼트 셰이더에서 동차 나눗셈으로 평가합니다. 뒷벽은 소실점 주변, 나머지 네 면은 하늘·땅·좌우 영역을 각각 참조합니다. 소실점과 뒷벽 수축률·원본 가로세로 비율에서 공간 크기를 계산한 뒤 가로·세로·깊이를 같은 길이로 맞춘, 입구가 열린 정육면체입니다. 이것은 촬영 당시의 실제 건물 치수를 복원한 모델이 아니라 사진 속으로 들어가기 위한 전시용 투영 공간입니다.

공간 모델은 하늘·왼벽·오른벽·바닥·소실점 뒷벽의 독립 메시 5개로 구성된 열린 정육면체입니다. 반투명 #fafafa 경계선을 유지합니다. 일반 드래그는 수직 방향을 유지하는 턴테이블 회전입니다. 좌우는 여러 바퀴 돌릴 수 있고, 상하는 ±80°에서 멈춰 극점을 넘어 뒤집히지 않습니다. 일반 드래그에서는 Z축 기울기가 생기지 않습니다. Shift+드래그 또는 오른쪽 드래그로 명시적으로 Z축을 회전할 수 있습니다. 터치는 한 손가락 회전·두 손가락 핀치 확대를 지원하며, 핀치 도중 손가락 비틀림이 모델을 기울이지 않습니다.

감도는 화면에서 보이는 모델 크기에 맞춥니다. 시작 자세와 드래그 시작·현재 좌표로 자세를 계산하므로 같은 드래그는 같은 결과를 냅니다. 조작 중에는 마우스를 바로 따라오고 놓으면 추가 회전 없이 멈춥니다. 상하 제한에 닿지 않은 구간에서는 경로를 되짚으면 시작 자세로 돌아옵니다.

모델과 원본 사진 확대 창의 배율 상·하한을 제거했습니다. 5면 모델은 카메라 투영 배율로 확대하므로 가까운 면을 지나 사라지지 않으며, 큰 배율에서도 계속 확대할 수 있습니다. 휠 감도는 이전 0.0015에서 0.003으로 2배 높였고, 배율의 로그를 보간해 큰 변화에도 일정한 반응을 줍니다. 화면상 확대 제한은 없고 부동소수점의 0·무한대 계산 결과만 무시합니다. 원본 사진의 가로세로 비율은 유지합니다.

모델 캔버스는 전체 뷰포트 크기의 가장 뒤쪽 레이어입니다. 초기 크기와 중심은 기존 중앙 사진 영역에 맞추지만, 확대하면 중앙 구역에 잘리지 않고 사진 타임라인·캡션·연표 설명 뒤까지 보입니다. 타임라인·캡션·설명은 모델 위에 남으며 해당 UI의 입력 영역이 우선합니다.

사진 밖 좌표는 샘플링 전에 버려 가장자리 픽셀 반복을 막습니다. 경계는 3px 중첩과 알파 페더를 적용하고 원본 외곽은 어둡게 감쇠합니다. 몰입형 공간의 하늘은 실제 큐브의 윗면에 배치하며, photo 또는 샘플링 gradient를 사용합니다. 예전 far-plane 설정도 이 버전에서는 윗면 사진으로 처리합니다. 움직임 줄이기 설정에서는 자동 진입 애니메이션을 생략하며 직접 드래그·확대 조작은 유지합니다.

## 입력 영역 분리와 사진 선택

왼쪽 사진 목록은 독립 스크롤 영역입니다. 휠·터치 스크롤로 보이는 목록의 기준선에 가까운 사진을 중앙에 선택하며, 활성 사진은 x축으로 24px 이동합니다. 입력을 멈춘 뒤 180ms가 지나면 해당 사진이 목록 기준선에 부드럽게 스냅합니다. 사진 클릭도 중앙 선택으로 연결되며 대기 중인 스크롤 선택을 취소해 클릭한 사진이 다른 사진으로 바뀌지 않습니다.

모델이 보이는 배경 영역의 휠·핀치는 오직 모델 확대·축소에만 사용합니다. 드래그는 모델 회전만 처리하며 사진 목록을 움직이거나 사진을 바꾸지 않습니다. 회전 드래그 뒤 클릭 이벤트가 발생해도 확대 창을 열지 않습니다. 공간 모델 더블클릭 또는 Enter는 원본 사진 확대 창을 열고, 단독 간판은 중앙에 크게 표시되며 클릭으로 확대 창을 엽니다. `< 되돌아가기` 또는 Escape로 복귀합니다.

오른쪽 시대 설명은 이전 버전의 여러 시대가 함께 보이는 표시 방식으로 복원했습니다. 현재 시대를 밝게 표시하고 뒤쪽 시대를 흐리게 이어 보여줍니다. 오른쪽 텍스트 스크롤은 모델과 사진 목록을 바꾸지 않습니다. 설명 문구 자체는 PDF에 근거한 기존 내용을 유지했습니다. 키보드 방향키·PageUp/PageDown으로 사진 이동, Home/End로 첫·마지막 사진을 선택합니다.

## 검증

실제 Chromium에서 5개 면과 외곽선, 텍스처 1개, 모델 휠·회전과 목록 스크롤의 분리, 사진 클릭 유지, 24px 이동, 이전 여러 시대 텍스트 표시, 되돌아가기 버튼의 실제 Pretendard 로딩·글자 크기·자간·색·외곽선 부재, 확대·복귀, 간판 중앙 표시, 모바일 너비와 단일 HTML 실행을 확인했습니다. 추가로 좌우 360° 초과 회전 중 수직 유지, 상하 ±80°에서 뒤집힘 방지, quaternion의 정상 값, 이전 상한을 넘는 100배 이상 확대와 하한 미만 축소, 2배 높인 줌 감도, 전체 화면 뒷레이어 및 목록 스크롤 분리를 검증했습니다. 콘솔 오류는 없습니다. GitHub에 푸시하는 것과 GitHub Pages 배포는 별개이며, Pages 공개 설정은 이 구현에서 변경하지 않습니다.

Three.js 0.170.0의 npm 배포 무결성을 SHA-512로 확인해 로컬 포함했습니다. 라이선스는 `vendor/THREE-LICENSE.txt`입니다.
