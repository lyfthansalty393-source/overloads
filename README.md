# 한국 간판 100년

첨부 사진 112장을 파일명의 연대순으로 배치한 스크롤 웹사이트입니다. 사진 파일의 바이트와 가로세로 비율을 유지했습니다. 건물·거리 사진 74장은 중앙의 5면 정육면체 공간으로 투영하며, 단독 간판·인쇄물도 중앙에 원본 비율의 큰 사진으로 표시합니다. 원래 있던 `11:3index.html`은 보존했습니다.

## VS Code에서 실행

1. 전체 폴더를 열고 VS Code Live Server로 `index.html`을 실행하거나, 터미널에서 다음 명령을 실행합니다.

   ```sh
   cd /workspace/overloads
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

2. 로컬 브라우저에서 서버의 `index.html`을 엽니다. 파일을 더블클릭하는 `file://` 실행은 ES 모듈·텍스처 보안 제한으로 지원하지 않습니다.
3. HTML·CSS·JS 분리본은 `index.html`, `styles.css`, `app.js`입니다. `archive.json`, `projections.json`, `vendor/`, `assets/`를 함께 유지합니다. npm 설치나 API 키는 필요하지 않습니다.
4. `single.html`은 CSS·JS·Three.js·JSON을 HTML에 합친 버전입니다. 원본 사진은 공통 `assets/photos/`에서 읽으므로 이 폴더를 함께 유지하고 동일한 HTTP 서버로 실행합니다. JSON 수정 후에는 `python3 scripts/build-single.py`로 다시 생성합니다.

## 사진과 설명

- 연대는 ZIP 이름이 아니라 사진 파일명의 앞 네 자리로 구분합니다. 파일명이 개별 촬영 연도를 증명하지 않으므로 UI에는 `1960s`와 같이 표시합니다.
- 설명과 제도 문구는 첨부 「한국 간판 100년 — 간판의 역사와 변천사 보고서」 6–12쪽의 시대별 내용을 요약했습니다. 보고서에 개별 사진 식별 정보가 없어 장소·작가·정확한 촬영일은 추정하여 붙이지 않았습니다. `archive.json`의 `sourcePage`가 PDF 페이지 근거입니다. 사진 설명은 해당 시대의 일반적 특징이며 개별 사진 재료 감정이 아닙니다.
- 왼쪽 사진을 누르면 그 사진으로 이동하고, 중앙 사진을 누르면 원본 비율로 확대합니다. 휠·핀치로 최대 8배 확대하고 드래그로 이동할 수 있습니다. 왼쪽 목록의 모든 사진을 확대할 수 있으며, 뒤돌아가기 버튼 또는 Escape로 복귀합니다.
- 전체 UI는 지정된 네 색만 사용합니다. 원본 사진과 사진에서 샘플링한 하늘 색은 원본의 색을 유지합니다. 별도 폰트 파일이 지정되지 않아 시스템 본문 산세리프 글꼴을 사용했습니다.

## Tour into the Picture 설정

`projections.json`에 사진별 설정을 분리했습니다. 세 예시는 `projection-examples.json`입니다.

| 예시 | 사진 | 초기 소실점 | 하늘 |
| --- | --- | --- | --- |
| 중앙 거리 | 1960-31.webp | 0.49, 0.49 | photo |
| 치우친 골목 | 1980-03.jpeg | 0.77, 0.50 | gradient |
| 넓은 하늘 | 1960-11.webp | 0.51, 0.56 | photo |

이 값들은 사진을 보고 지정한 초기 추정값입니다. 다른 공간 사진은 공통 초기값에서 시작하므로 전시 전 사진별 보정이 필요합니다. 사진만으로 실제 건물 깊이나 가려진 내용을 복원할 수는 없습니다.

주소에 `?debug=1`을 붙이면 5개 영역, 소실점, 뒷벽 핸들이 표시됩니다. 가운데 점은 소실점, 나머지 두 점은 뒷벽의 좌상단·우하단입니다. 드래그 중에 공간을 재구성하며, 하늘 모드 선택과 JSON 저장을 지원합니다. 저장한 JSON으로 `projections.json`을 교체합니다. `leftWall.enabled` / `rightWall.enabled`를 false로 두면 그 면은 #101010이 됩니다. VP는 뒷벽 내부에 두어야 합니다.

중앙은 BoxGeometry 대신 별도의 PlaneGeometry 5개를 사용합니다. 한 번 읽은 사진 텍스처를 공유하고, 각 면의 3×3 homography를 프래그먼트 셰이더에서 동차 나눗셈으로 평가합니다. 뒷벽은 소실점 주변, 나머지 네 면은 하늘·땅·좌우 영역을 각각 참조합니다. 소실점과 뒷벽 수축률·원본 가로세로 비율에서 공간 크기를 계산한 뒤 가로·세로·깊이를 같은 길이로 맞춘, 입구가 열린 정육면체입니다. 이것은 촬영 당시의 실제 건물 치수를 복원한 모델이 아니라 사진 속으로 들어가기 위한 전시용 투영 공간입니다.

사진 선택 시 카메라가 입구에서 큐브 내부까지 진입하고, 넓은 시야각으로 다섯 면을 보여줍니다. 마우스 이동에 따라 좌우 최대 20°, 상하 최대 10° 범위의 회전과 작은 위치 이동을 적용해 면마다 다른 시차를 만듭니다. 바깥쪽 박스를 회전시키는 방식이 아닙니다. 와이어프레임과 테두리는 표시하지 않습니다. 원본 사진 확대 보기에서는 원본 가로세로 비율을 유지합니다. 내부 투영의 벽·천장에는 원근 변형이 적용됩니다.

사진 밖 좌표는 샘플링 전에 버려 가장자리 픽셀 반복을 막습니다. 경계는 3px 중첩과 알파 페더를 적용하고 원본 외곽은 어둡게 감쇠합니다. 몰입형 공간의 하늘은 실제 큐브의 윗면에 배치하며, photo 또는 샘플링 gradient를 사용합니다. 예전 far-plane 설정도 이 버전에서는 윗면 사진으로 처리합니다. 움직임 줄이기 설정에서는 진입 애니메이션과 시점 회전을 생략합니다.

## 고정 목록과 스크롤 장력

왼쪽 사진 목록은 고정된 독립 스크롤 영역입니다. 목록 위에서 직접 휠·터치로 스크롤할 때만 목록이 움직입니다. 중앙 또는 오른쪽 영역의 스크롤은 사진 이동에만 사용하며 페이지·왼쪽 목록을 움직이지 않습니다. 왼쪽 사진 클릭은 목록의 위치를 변경하지 않고 중앙 사진을 선택합니다. 중앙 사진 클릭은 기존 확대 창을 엽니다.

이동은 스프링과 감쇠를 사용하며, 입력이 180ms 동안 멈추면 가장 가까운 사진 번호로 스냅합니다. 선택된 사진에서는 진입이 안정되어 머물러 볼 수 있습니다. 키보드 방향키·PageUp/PageDown으로 이전·다음, Home/End로 처음·마지막 사진을 선택합니다. 모든 112장에 멈출 수 있으며, 간판 사진은 평면 사진으로 중앙에 크게 표시합니다. 오른쪽 제도 설명은 위치를 이동시키지 않고 현재 시대의 내용만 바꿉니다.

## 검증

실제 Chromium에서 큐브의 동일한 세 변 길이와 내부 카메라 위치, 고정 목록, 스프링 스냅, 선택 이동, 간판 중앙 표시, 확대·복귀, 5개 메시, 텍스처 1개 및 콘솔 오류 부재를 확인했습니다. GitHub에 푸시하는 것과 GitHub Pages 배포는 별개이며, Pages 공개 설정은 이 구현에서 변경하지 않습니다.

Three.js 0.170.0의 npm 배포 무결성을 SHA-512로 확인해 로컬 포함했습니다. 라이선스는 `vendor/THREE-LICENSE.txt`입니다.
